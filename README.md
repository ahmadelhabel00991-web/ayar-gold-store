# عيار جولد — متجر الذهب الذكي

نسخة اختبار ويب لمتجر ذهب إلكتروني عربي RTL مع شاشة أسعار محلية، تسعير تلقائي، منتجات ومخزون وطلبات ولوحة تحكم.

- المتجر: `index.html`
- لوحة التحكم: `admin.html`
- بيانات الاختبار تُحفظ محليًا داخل المتصفح في نسخة GitHub Pages.
- دخول لوحة الاختبار: `admin` / `ChangeMe123!`

> هذه نسخة اختبار فقط، وليست بيئة إنتاج أو قاعدة بيانات مركزية.
